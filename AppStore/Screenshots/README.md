# ReadAloud 1.0 screenshot plan

Capture on a current large iPhone size after the final manual smoke pass.

Recommended sequence:

1. Library — several imported books/documents with Continue Listening visible.
2. Project Detail — artwork, chapter list, progress, voice/speed, and offline status.

4. Offline Audio — Ready Offline / generation state and storage-aware controls.
5. Settings / Pro — ReadAloud defaults, themes, and the Pro plan surface.
