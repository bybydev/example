Old apps reject v5 rather than silently ignoring its edits. Earlier headers containing mediaEdits are rejected. No Mac schema changes.

- Persisted clips, raw recognition, native word anchors and manual source/project intervals remain in the full original project clock. Media commands do not delete/re-time them or touch source bytes. This preserves later reset/expansion.

- IOSCaptionSnapshot derives clipped output words/cues without mutating canonical recognition. Completely outside units are omitted only from output. A cut-through unit retains its full text, with only its output interval clipped; no partial-word transcript/alignment is invented. Reset/undo restores excluded text. ## Media, crop and audio

IOSPreviewComposition.mediaGraph intersects original clips with the retained range, derives identity-speed source/output segments, then honors actual track intersections/offsets. Skip excluded clips before resolving source URLs. Cover leading/inter-clip/trailing gaps with explicit black instructions. MP4 final validation uses document.outputDuration, not the full original length.

Preferred source transform is followed by IOSMediaEdits.placement into the project rectangle. Fit uses the smaller axis scale, Fill the larger, then zoom applies. Normalized pan moves only an overflowing dimension (0 = left/top, 1 = right/bottom); a smaller dimension is centered. Inverse-transform the project viewport to a source crop rectangle, clipped to natural bounds. Framing transforms never move caption output coordinates.

previewSize(for:) defines the even raster size used by the media composition. IOSStyledCaptionOverlay first fits that actual raster viewport inside its view, then lets the common renderer fit the project canvas. This removes mismatched nested aspect fits from even-pixel rounding, including extreme/custom canvas ratios. Actual native pixel parity is not verified.

originalAudioMix(trackID:volume:) is shared by AVPlayerItem and AVAssetReaderAudioMixOutput. It applies one constant gain to the original first audio track(s) in the shared composition. No second player.volume multiplier is added. Zero produces muted source audio; no amplification, background music or new track mixer. Existing P5 bounded PCM/AAC writer settings remain.

A valid retained range may contain no source samples. IOSBlackClockAsset caches a tiny 16×16 single-frame H.264 temporary file at app runtime, holds it across that range and supplies a real native playback clock. Its composition instruction is black; videoIntervals is empty and it adds no audio. Export stays intentionally black/silent with any manually retained captions. It is never used when an expected retained original/track is missing or corrupt—those still fail. No such file was generated/downloaded by the agent.
