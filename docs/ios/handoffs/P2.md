## Source layout and contracts

IOSLocalTranscriber owns inference, IOSSpeechDecoder bounded AVFoundation windows, IOSWordMapper Unicode/time mapping, IOSTranscriptionController/IOSSpeechJob queue integration, IOSRecognition domain, repository saveRecognition publication and IOSTranscriptionView detail card. IOSProjectsModel owns one controller; normal root starts recovery. JobQueue state is authoritative, not duplicated in another job state machine.

Each source core is <=24 seconds; read up to two seconds of context each side (<=28 seconds). PCM sample offsets use buffer presentation timestamps; gaps become silence. No full-file concatenation or audio prefetch. Output/raw metadata necessarily scales with transcript length. Midpoint core ownership plus conservative same-acoustic-word overlap reconciliation; real boundary quality awaits user samples. First audio track is decoded; no advanced audio mixing.

Queue payload captures project/revision/language. A stale revision fails, preserving newer work. Explicit Retry may capture the current revision and selected language only if no recognition exists. If its operation already published the result, retry/restoration reuses it rather than rerunning/overwriting. Partial recognition is not checkpointed; interruption restarts inference. Publication precedes queue success. Cancellation after atomic publication can legitimately finish successfully.
