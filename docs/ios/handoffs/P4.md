## Integrated values and behavior

- Fonts: Modern=AvenirNext-DemiBold, Bold=HelveticaNeue-Bold, Serif=Georgia-Bold, Mono=Menlo-Bold. If a named face is unavailable, use emphasized system. Explicit cascade includes PingFangSC-Semibold, HiraginoSans-W6, AppleSDGothicNeo-Bold, Thonburi-Bold, AppleColorEmoji and the system descriptor. Core Text does shaping/fallback; no downloaded/custom font assets.
- Default style: Modern, size 0.06 of the shorter canvas edge, white text, yellow accent (1,0.8,0.12), black outline 0.045 of font size, black background alpha 0.6, center position (0.5,0.82), no effect. Size range 0.025–0.12, outline 0–0.12, RGBA/position components finite 0–1.
- Templates: Spotlight=Bold/highlight/no global background; Karaoke=Bold/mint progressive text fill; Pop=Modern/pink/size 0.075/outline 0.06/no global background; Soft Fade=Serif/size 0.055/no outline/background alpha 0.5/fade. Templates preserve current position. Values remain independently editable; no persistent template ID/marketplace schema.
- Effects: highlight uses active native/edited word intervals and contrasting text over an accent word background. Karaoke fills already-spoken words and progressively reveals the current timed unit; fragments follow logical UTF-16/run order and RTL direction across wrapping. Pop pulses the caption by at most 12% for <=180 ms after a word start. Fade ramps <=200 ms at the first/last visible-word envelope. Half-open cue gating is inherited from CaptionSnapshot. Overlapping word timing is retained. No inferred extra word boundaries/timestamps.
- Position: normalized top-left output center, never view points. Renderer clamps the whole caption block inside a 2% safe inset and reserves pop headroom. Horizontal/vertical sliders and Top/Center/Bottom actions are exposed; captions cannot be dragged outside the output by rounding.
- UI: Captions/Style/Templates below the existing stable preview/transport/timeline. Scrollable style controls and disclosures keep footage visible. No template auto-plays media; choose then Play/scrub to see the effect on current footage. Device Reduce Motion still applies to surrounding UI animation/autoscroll; the user's saved content effect uses the same media-time behavior in preview/output.

## Shared renderer and P5 interfaces

CaptionSnapshot now freezes canvas and effective style as well as revision/edited cues/words; its UUID distinguishes working drafts. CaptionMotion has no display/wall-clock timer. CaptionRenderer owns only a one-cue layout cache (base/accent/contrast Core Text line variants and word fragments); create a separate instance for each preview/export owner and never use it concurrently across queues. Apple recommends keeping Core Text layout objects on one operation/queue/thread.

All text is shaped from the full attributed Unicode string. Native line-break APIs choose UTF-16 ranges; Core Text glyph positions/advances/string indices map words without substring-width approximations. Color variants use identical typesetter ranges. Installed fallback glyphs, including intrinsically colored emoji, retain their font drawing; karaoke does not promise tinting color emoji. Limits: <=16,384 UTF-16 units and <=8 lines fitting the canvas. Failure is cached for the active snapshot/cue and surfaces as a clear split/reduce-size error, not truncated output. Render pixels obey existing RenderCanvas <=1920 per edge and <=1080*1920 pixels.

Exact APIs:

```swift
let document = try await session.savedDocument() // drains latest edits; refuses dirty/failed save
let snapshot = CaptionSnapshot(document)     // freeze once per P5 operation
let renderer = CaptionRenderer()             // owned by this render queue

// Bottom-left CGContext; output bounds aspect-fit the saved project canvas.
try renderer.draw(snapshot: snapshot, at: projectTime, in: context, bounds: bounds)

// Transparent sRGB CGImage?; nil means no visible cue, errors throw.
let overlay = try renderer.overlay(snapshot: snapshot, at: projectTime, canvas: outputCanvas)

// Oriented source frame at the same project time, project/output aspect-fit plus black bars.
let frame = try renderer.composedFrame(orientedFrame: orientedSourceFrame,
    snapshot: snapshot, at: projectTime, canvas: outputCanvas)
```

UIKit preview only flips its CGContext coordinate system and calls draw; it no longer draws a separate SwiftUI Text/animation approximation. Bitmap output and CI composition call that exact layout/draw/effect path. The P0 ClipFrameCompositor is explicitly historical/fixture-only. P5 owns final timestamp mapping, profile, actual source readers/composition/audio, pixel-buffer/writer integration, cancellation, jobs, SRT and delivery. Use edited caption content/times, not raw recognition. Freeze document/assets/profile; surface render errors and never report output success before finalization. SRT omits styling. No P5 export/commerce implementation is claimed here.
