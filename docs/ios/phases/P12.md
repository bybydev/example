## Implementation sequence

1. P12a: implement folders/collections/tags/favorites, duplication/archive, history/version restoration and project portability per mapped inventory. Preserve stable internal links and safe new identities when importing/duplicating projects.

2. P12b: select an explicitly approved optional backup/sync approach, define document/media transfer and offline conflict/version rules, and implement recovery. Keep local content usable without sign-in/network and never last-write-wins away manual edits silently.

3. P12c: implement team/shared project workspaces, roles/permissions, timestamped comments/review links/approval and shared brand kits. Enforce permissions at the authoritative service boundary, define invite/share visibility and revoke behavior, and preserve offline change provenance.

4. P12d: integrate AI allowances/credits/usage dashboard and team billing/seats against an actual authoritative usage/service contract. Use stable request/idempotency keys; define failed/cancelled/retried request settlement and restoration behavior. Do not treat client counters as billing truth.

6. Design organization/history/conflict/team/usage panels before UI edits. Document privacy/deletion/media retention, access checks and provider cost/data flow. Do independent local work while concrete backend/provider/account choices are pending; do not deploy infrastructure unrequested.
