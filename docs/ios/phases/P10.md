## Implementation sequence

1. Implement caption-independent text, titles/hooks/lower-thirds/CTA, progress bars, bubbles, emoji/stickers/custom shapes/cards/gradients and layer ordering/blend/opacity/animation controls using the shared scene engine.

2. Implement tracking/face/object association, masking and motion-aware overlays with actual supported algorithms/provider contracts. Define how tracking data follows trim/speed changes and how users correct/loss-of-track cases.

3. Build the full categorized template gallery, actual-footage previews, favorites/recents/collections and editable presets. A template composes supported project/style/overlay values rather than storing only a flattened preview image.

4. Implement custom/duplicate/share/import/export templates, version/dependency validation, missing-font/asset handling and safe identity remapping. Keep imported designs untrusted data and reject arbitrary executable content.

5. Implement multi-brand kits, logos/watermarks/palettes/fonts, global application and style randomizer. Integrate P5 premium-brand gating; shared team kits remain connected to P12 permissions/versioning when available.

6. Refine template/style distinction and selection scope in UI. Preserve existing project overrides and source media on apply/undo; preview and final render use identical layer/effect contracts.

## Contracts and preservation

- Template/brand schemas are versioned, portable and reference required asset/font dependencies.
- Overlay layers retain stable IDs and source/project timing; tracking is cached derived data with valid source/revision keys.
- Applying a design is reversible and explicitly scoped; commerce never prevents reading existing designs/projects.

Preserve existing Mac behavior/data/purchases. No implicit cloud calls, paid use, model downloads, external publishing or deployment. Do not introduce placeholder controls/results and call them complete.

## Implementation completion criteria

- All owned overlay/template/brand items work through the real editor, including editable actual-footage previews.
- Template sharing/import preserves dependencies, identity and recoverable errors.
- Tracking/masking data and supported limits are explicit; advanced features are not counted via static stickers.
- P5 brand gate integration is complete; P12 shared-brand dependency is recorded until implemented.
