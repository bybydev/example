## Implementation sequence

1. Audit all 467 ledger items against actual app/service paths and phase handoffs. Identify dead controls, placeholders, dependency-pending integrations, accepted limitations and unimplemented behavior; fix scoped correctness gaps rather than bulk-checking categories.

2. Implement professional caption checks: speaker/non-speech labels, reading speed, overlap/duration, contrast, multilingual validation, accessibility conventions and independent transcript review. Integrate actionable findings with the editor.

3. Implement VoiceOver semantics, Dynamic Type for controls, keyboard access, Reduced Motion, high-contrast/color-safe presets and flash/animation warnings. Preserve precise media layout while surrounding UI adapts accessibly.

4. Review source/project/cache separation, migration and autosave failure, missing-source/font relinking, privacy/deletion, temporary storage, queue restoration and export cancellation/recovery. Add robust error handling and safe incremental reuse where required.

5. Review deterministic preview/export timing/font/easing/color, audio sync after temporal edits, model/session lifetime and bounded processing. Address source-level memory/thermal/storage risks without conducting device benchmarks.

6. Reconcile every risk and feature integration with evidence, then prepare focused user testing instructions covering long media/languages/formats/compact UI/interruption and migration. Do not set up CI, run builds/tests unless asked, install on devices or claim release readiness from static review.
