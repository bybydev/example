## Implementation sequence

1. P8a: implement silence/filler/retake analysis, smart jump cuts/pacing and automatic zoom proposals. Preserve genuine speech context, preview the exact cut ranges and let users reject individual changes.

2. P8b: implement scene/highlight/hook detection/generation, long-to-short conversion, automatic reframing and repurposing. Results reference stable source/clip intervals rather than destructive replacement videos.

3. P8c: implement licensed stock search/B-roll suggestions and insertion, opt-in generated B-roll, image/audio enhancement, gaze/background/face effects where feasible. Verify each actual model/provider/license capability and record limitations separately; no capability assumed from the roadmap label.

4. P8d: natural-language orchestration builds validated proposals from already-supported P6 operations. Validate IDs, times, sizes, rights and input revision before apply; never execute arbitrary model-provided code or unbounded commands.

5. Integrate review/compare/apply/undo and cancel/retry states into the existing editor. Remote services require explicit data/cost authorization. Recover partial downloads/generation without charging/reapplying twice.

6. Keep proposed cuts, inserted stock/generated sources, resulting edit graph and export snapshots traceable. Update constraints and pending IDs rather than advertising nonfunctional AI buttons.

## Contracts and preservation

- Suggested edits are typed, bounded operations with expected revision and reversible application.
- Source and generated/stock assets retain provenance/license/consent metadata.
- Provider failure or rejected suggestions never alter existing media/edit state.

Preserve existing Mac behavior/data/purchases. No implicit cloud calls, paid use, model downloads, external publishing or deployment. Do not introduce placeholder controls/results and call them complete.
