## Implementation sequence

1. P6a: implement multi-track trim/split/merge/reorder/delete/duplicate, picture-in-picture/layer placement, text-based media editing and snapshot operations. Preserve source originals; each clip instance has independent identity and mapping.

2. P6b: implement speed/ramping, reverse/freeze, crop/rotate/flip/aspect/zoom/pan/keyframes/transitions and visual effects from the inventory, including color/LUT/filters, blur/replacement/face obfuscation, stabilization and subject framing. Document actual dependencies/provider constraints for advanced methods.

3. Specify forward/inverse time transforms, caption clipping/duplication/gap rules, audio behavior and selection/undo semantics for every temporal operation. A caption in a trimmed-away region must not play at the old absolute position.

4. P6c: implement voice/music/effect import, extraction/replacement/recorded and AI voiceovers, trimming/fades/envelopes/ducking/mixing, volume/loudness controls and enhancement/noise/echo/isolation. Licensed libraries need real rights; remote synthesis needs opt-in and actual provider selection.

5. Integrate reviewed contextual video/audio controls into P3's hierarchy, numeric precision and command system. Do not add a second timeline/document/player owner.

6. Update the shared scene/composition/export pipeline for every supported effect and temporal transform. Define cache invalidation, schema migration/recovery and safe render-job revision snapshots.

## Contracts and preservation

- One source-to-project time model handles captions, video and audio for nonlinear edits.
- Effects/tracks/keyframes are serializable non-destructive graph nodes with stable IDs and inverse commands.
- Preview and export implement the same operation semantics; originals/caches remain separated.

Preserve existing Mac behavior/data/purchases. No implicit cloud calls, paid use, model downloads, external publishing or deployment. Do not introduce placeholder controls/results and call them complete.

## Implementation completion criteria

- All mapped video/audio items are implemented/integrated or individually reported with accepted constraints/dependencies.
- Trim/reorder/speed/reverse operations maintain explicit caption/audio mapping; undo restores a coherent graph.
- Multi-track preview/export, media assets and persistence share one graph/version model.
- No generalized placeholder effect or unlicensed music library is counted as a finished feature.
