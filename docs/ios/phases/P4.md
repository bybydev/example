## Implementation sequence

1. Implement shared scene/layout evaluation for timestamp, canvas/profile, words/cues and resolved fonts/styles. Specify project coordinates, line wrapping, baseline/position/safe-area and output-resolution scaling.

2. Deliver typography properties from the ledger: font library/import, weights/spacing/case/alignment, colors/gradients/outline/shadow/glow/blur/backgrounds, per-word/speaker styling, placement/rotation/scale and saved global/local overrides.

3. Implement every mapped animation primitive and combination, including per-word karaoke/reveal, entrances/exits, springs, sweeps, blur/glitch/shake, independent timing/delay/intensity/easing/keyframes and loops. Derive state from media time, not wall-clock view animations.

4. Handle Unicode graphemes, emoji, punctuation and language-aware line layout. Establish font availability/licensing/import validation and explicit fallback/warnings; P7 adds detailed bilingual/RTL/CJK integration.

5. Integrate reviewed style/animation controls with P3 selection/commands and actual video preview. Provide reusable saved styles and premium animation catalog data without embedding entitlement checks in the renderer.

6. Version style/preset serialization and cache keys; edits/undo preserve unrelated per-word overrides. Define deterministic procedural effects and random seeds. Compare representative same-timestamp scene descriptions for preview/export adapters by allowed source/fixture review.

## Contracts and preservation

- Same project/time/profile/fonts produce the same glyph/effect output regardless of playback history.
- Caption style values are serializable/versioned; app commerce gates access, not domain parsing/rendering of existing projects.
- Effects support paused/backward seeking and arbitrary export sampling.

Preserve existing Mac behavior/data/purchases. No implicit cloud calls, paid use, model downloads, external publishing or deployment. Do not introduce placeholder controls/results and call them complete.

## Implementation completion criteria

- Typography and all mapped animation behaviors have real scene implementations and integrated controls; none depends exclusively on SwiftUI live animation.
- Preview uses the planned shared evaluator and export adapter can consume the same results.
- Font/Unicode/style migration/error cases have defined handling; unknown device/export measurements are reported.
- Every owned feature ID is accounted for, including premium animation catalog; saved style remains editable.
