## Implemented scope

Captions/Style/Templates tools preserve the stable footage player, selection and project clock. Four built-in font choices, normalized size, text/accent/outline/background colors, outline width and background toggle; output-coordinate horizontal/vertical placement plus Top/Center/Bottom. Spotlight/Karaoke/Pop/Soft Fade presets apply editable properties and preserve placement. Templates and continuous controls participate in session undo and serialized autosave.

One Core Text renderer supplies whole-string Unicode shaping/wrapping, script/emoji/system font fallback, output layout and all four effects. A pure evaluator derives highlight, progressive karaoke, word-triggered pop and word-envelope fade from actual edited word timing. UIKit preview and transparent sRGB bitmap/CI frame adapters share the same draw path. Raw recognition/native anchors/originals remain unchanged. Schema v4 reads v1–v3 and preserves style on duplicate.

No custom font import, brand kits, marketplace, AI styling, tracking, keyframe editor or large effect catalog. P5 export jobs/files/audio/commerce are not implemented. See [../handoffs/P4.md](../handoffs/P4.md) for exact renderer input/output and bounds; existing P0 fixture code is not a second shipping renderer.
