# BYOKchat

BYOKchat is an iOS-only, Bring-Your-Own-Key (BYOK) AI chat client.

## Features
- **Bring Your Own Key**: Connect directly to OpenAI, Anthropic, Gemini, xAI, DeepSeek, OpenRouter, NVIDIA, Groq, Alibaba Qwen, Together AI, Fireworks AI, z.ai, Moonshot AI (Kimi), MiniMax, Mistral AI, Ollama, LMStudio, or custom OpenAI-compatible endpoints.
- **Local-First & Private**: Conversations, attachments, and analytics are stored locally on-device with SQLite FTS5 full-text search.
- **Projects & Library**: Organize chats into projects and manage saved files and images.
- **MCP Support**: Connect remote Model Context Protocol (MCP) servers with per-tool permissions.
- **Usage & Analytics**: Track token usage, estimated costs, and conversation analytics.
