Catalog version `2026-10-07`, verified against the official sources below on 2026-10-07. The bundled JSON is a Swift-package resource and works offline. All rates are USD per 1,000,000 tokens. These are standard direct-API estimates; account discounts, free-tier eligibility, special modes, and later provider price changes may differ.

OpenAI long-context pricing applies from 272,000 input tokens; [the API pricing overview](https://openai.com/api/) describes standard rates below 272K. Anthropic's covered models use standard rates across their context window. DeepSeek peak hours are Monday–Friday UTC 01:00–04:00 and 06:00–10:00. The provider explicitly documents `deepseek-v4-flash` as a legacy accepted name served and billed by the Flash model. No arbitrary model prefixes or fuzzy aliases are matched. A request crossing a time bucket/rate expiry is incomplete.

Input normalization includes cache reads and writes; the calculator subtracts those subsets before applying ordinary input rates, then prices each subset separately. Reasoning is already included in normalized output: Gemini candidates plus thinking; other supported APIs report inclusive output. Anthropic 1-hour writes are a subset of total writes. Missing write duration, missing cache usage for a rule with cache pricing, unsupported additional charges, or missing required usage/rates prevents a complete estimate. Cached Gemini usage is incomplete because storage is billed by token-hours outside the request receipt. Server-side tool charges and unsupported OpenAI service tiers are not silently priced as ordinary tokens.

Cached model discovery rates take precedence only for the same account/provider and exact model ID. Valid zero prices are retained. Rates from different sources are not combined. A partial model-API rule remains partial rather than borrowing incompatible catalog dimensions. Bundled rates require the canonical provider identity and default endpoint; proxies, regional overrides, and custom-compatible accounts use discovered pricing or unavailable cost. Unknown local/free-suffixed models are not inferred to be free. The resolver never makes a network call.

Changing an account's provider, endpoint, API paths, authentication choice, headers, or request metadata invalidates its cached discovery prices while preserving model selections and capabilities. Discovery finishing from the old configuration cannot restore those prices. Label/default-model/enabled-state edits retain prices. Each tool round reads the current account and cached prices together; a configuration change during a request prevents a complete calculated receipt. Refresh model discovery to obtain rates for the new configuration. Saved historical receipts remain unchanged.

Before each request, capture source, version, verification/source link, model ID, rates, and context/cache/time rules. After inference, complete reported cost wins; otherwise calculate only supported dimensions. The saved per-request receipts and whole-turn completeness live in billing metadata and survive lightweight index round-trips. Failed later requests preserve known earlier costs. Catalog/model refresh changes future requests, never saved amounts.

Persist a completed request receipt as soon as the provider completion event arrives, before checking cancellation or waiting for stream termination. A later cancellation/transport failure changes turn status but retains the observed usage and cost. Such a request is recorded as completed in performance telemetry, rather than both completed and failed. Cancellation before a completion event remains an attempted request with unknown cost.

OpenRouter normal `usage.cost` is the account charge; streaming keeps the final total once, not running totals. When `is_byok` is true, the OpenRouter account fee and upstream provider inference have different scopes. This implementation conservatively retains only the reported OpenRouter charge as an incomplete scoped subtotal, does not add `upstream_inference_cost`, and does not claim complete total inference spend. See [Usage Accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting) and [API schema](https://openrouter.ai/docs/api-reference/overview). xAI USD ticks decode as Decimal before division by 10,000,000,000; malformed/missing costs fall through without breaking chat.

A complete estimate means complete under its saved supported rule. It is still approximate. Partial calculated/mixed amounts use `~` plus a partial label, because they may be above or below actual charges. Only a retained provider-reported subtotal justifies `≥`. Unknown costs have no numeric amount; explicit reported zero remains known.

Remote catalog refresh, manual price editing, and a durable spend ledger are deferred. Current totals represent the remaining saved chat history; removing responses can reduce totals.
