Explain why this API design is easier to maintain.
It keeps the public surface small. The provider-specific details stay behind one boundary, so the app can add new models without changing chat code. Persistence remains provider-neutral, tests can target the runtime independently, and UI state does not need to know wire formats. That is the maintainable split.
